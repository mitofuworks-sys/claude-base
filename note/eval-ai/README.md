# 有料note：評価コメント×生成AI　作成メモと販売プラン

- 記事本文：`article.md`（有料ラインの位置は本文中に印あり）
- ハッシュタグ：`hashtags.md`
- 調査日：2026-10-12

## 1. ジャンル選定の根拠

| 判断軸 | 調査結果 | 採用理由 |
|---|---|---|
| 伸びているジャンル | note公式の約30万件分析（2026年1月発表）で「AI活用」「SNS運用」「育児」が急成長 | AI活用を選んだ。育児は実体験が価値の中心になるため、書き手の体験を使わない方針と合わない |
| 単価 | 同分析で、売れている記事の平均単価は実用ノウハウ系1,842円、読み物系983円 | 読み物ではなく、実用ノウハウ（テンプレート型）にした |
| AI活用の弱点 | 「AI副業」「汎用プロンプト集」は飽和しており、AIっぽい一般論は離脱されやすいという指摘が多い | 「副業で稼ぐ」系を避け、**業務の具体的な一場面**に絞った |
| 読者の悩み | 管理職1,008名調査（コーレ社）で、AIを使いこなせない層の最多は課長・リーダー職（29.3%）。阻害要因はセキュリティ不安とアイデア不足。帝国データバンク調査では懸念の最多が「情報の正確性」（50.4%） | 管理職に絞り、「個人情報」「正確性」の不安に正面から答える設計にした |
| 時期 | 3月決算の会社では、9月末で上期が終わり、10〜11月が上期評価の時期 | **今まさに困っている人がいる**。12〜1月の年末評価でも再び需要が出る |

## 2. 競合との差別化

「管理職×AI×評価コメント」には、すでに無料・有料の記事がある（例：「10人の評価を1分で」「4時間→29分」のような時短アピール型、ITmediaやAI研修会社の無料プロンプト記事）。調査で見えた競合の弱点と、この記事の対策は次のとおり。

| 競合に多いもの | この記事 |
|---|---|
| 「1分で完結」など時短を強調し、AIに評価そのものを書かせる | 評価は人が決め、AIは整理と点検を担当する。評価者の責任を軽く扱わない |
| 個人情報は「入れないように」と一言だけ | 具体的な置き換え表と、入力前の30秒チェックをつける |
| 架空の実績を書いてしまう問題にほぼ触れない | 全指示文に「書かれていない事実は書かない」「根拠不足を表示」を組み込む |
| コメント作成だけで終わる | メモ整理→矛盾点検→評価エラー点検→下書き→ギャップ整理→面談台本→ロールプレイまで、一連の流れにしている |
| 特定サービス前提 | ChatGPT／Claude／Gemini／Copilotのどれでも使える |
| 書き手の実績頼み（「私はこれで〜」） | 実績を名乗らない。入力例・出力例はすべて「想定例」と明記 |

## 3. 響かせるための書き方（調査から反映したこと）

- タイトルは、検索語（評価コメント・AI）を前半に置き、「3つの失敗」「7つの指示文」という具体的な数字を入れた。読者を「書けない人」扱いせず、AIを安全に使いたい有能な管理職に向けた言い方にしている
- 無料部分で、悩みの原因（文章力ではなく材料不足）と、丸投げの3つの失敗、3つのルールまで出し切る。無料で読んでも役に立つ内容にして、「この続きの道具が欲しい」と思わせる
- 有料ラインは「有料部分で何が手に入るか」の一覧の直後に置く（向いている人・向いていない人も明記し、買ってから後悔させない）
- 有料部分は「コピーして穴埋めするだけ」で使える指示文を中心に、想定例とチェックリストをつけた
- 誇大表現（「必ず」「誰でも」「〇分で完了」）は使っていない

## 5. 投稿手順（あなたの作業）

1. noteで新規記事を作成し、`article.md` のタイトルと本文を貼り付ける（表やチェックボックスは、noteで表示が崩れる場合は箇条書きに直す）
2. 本文中の「（▼ここに note の「有料エリア設定」ラインを入れる ▼）」の位置に有料ラインを設定し、その印の行と前後の `---` を削除する
3. 価格を980円に設定する
4. `hashtags.md` のタグを設定する
5. 見出し画像をつける（公式ヘルプでも推奨されている）
6. 公開前に、会社員の副業規程などに問題がないか確認する

## 6. 集客（売上を左右するのはここ）

調査では「売れない最大の原因は集客不足」という指摘が多かった。noteに置くだけでは、新規アカウントの記事はほとんど読まれない。

- X（旧Twitter）などで、無料部分の要点を小出しにして、記事へ誘導する。投稿文の例：

> 評価コメントをAIに丸投げすると起きる3つの失敗
> ①やっていない実績を書く
> ②部下の個人情報を入力してしまう
> ③全員同じ文章になる
> 指示文の書き方で、3つとも防げます。

> 評価コメントに時間がかかるのは、文章を書く作業のせいではありません。
> 半年分の「事実」を思い出して集める作業に時間がかかっているからです。
> AIに最初に頼むべきは、文章ではなく「事実の整理」です。

> 部下の評価、AIに決めさせていませんか。
> AIの役目は、あなたが決めた評価と事実に矛盾がないかの点検です。
> 判断は人、点検はAI。この分担なら安心して使えます。

- 同じテーマで、無料記事を2〜3本（例：「評価エラー6種類の解説」「1on1の質問例」）出し、有料記事へ内部リンクする

## 7. 正直な見通し

- 売上は保証できない。フォロワーのいない新規アカウントだと、集客をしなければ1件も売れないことも十分ありうる
- 元手はかからない（5万円は使わずに済む）。もし使うなら、見出し画像の作成ツール程度で足りる
- 記事は生成AI（Claude）が書いたもの。公開前に必ず一度読んで、違和感のある箇所は直してほしい。AIで作成したと明記するかどうかは、あなたの判断で決める
