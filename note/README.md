# AIが5万円で稼ぐ：販売ロードマップ

作成日：2026-10-12　作成：Claude（AI）

依頼主の作業は「コピーして投稿する」「数字を記録する」の2つだけ。それ以外の判断は、すべてこのファイルに書いてある。

## 1. 結論：何を、どう売るか

**アカウントそのものを商品にする。**

テーマは「AIが『5万円で稼いで』と頼まれ、ゼロから売上をつくる挑戦の記録」。無料の連載で人を集め、挑戦の中で生まれた実用ノウハウを有料記事として売る。

| 種類 | 記事 | 価格 | 役割 |
|---|---|---|---|
| 無料 | 第1話：AIが2回ダメ出しされた話 | 0円 | 話題になって、フォローしてもらう |
| 無料 | 第2話：noteで売れる5つの条件（公式データ） | 0円 | 役に立つ情報で、信頼してもらう |
| 有料① | AIの答えが的外れになる5つの原因と防ぐ指示文 | 500円 | 最初の売上 |
| 無料 | 第3話：週報（数字を全部公開） | 0円 | また見に来てもらう |
| 有料② | フォロワー0からnote有料記事を売る全手順 | 980円 | 2つめの売上 |
| 有料 | マガジン（有料①＋②＋今後の有料記事） | 1,180円 | まとめ買い（単品合計1,480円の約8割） |

## 2. なぜこの戦略なのか（考え直した理由）

最初の2回の企画（依頼主が作ったプログラムの解説、管理職向けの評価コメント記事）は失敗だった。原因は、**「データで伸びているジャンル」と「調査で見つけた悩み」を組み合わせて、実在しない読者を作ったこと**。

一から考え直して、次の4つの事実から今の戦略を決めた。

1. **フォロワー0のアカウントは、記事を置くだけでは読まれない。** 売れない原因として多く挙がるのは、中身より先に集客不足だった。だから、まず「人が集まる理由」が要る
2. **人が集まる理由になるのは、ほかの誰にも書けない一次情報。** このアカウントが持っている一次情報は「AIが自分で稼ごうとして、人間にダメ出しされた記録」だけ。依頼主の実績は使わない
3. **お金を払ってもらえるのは、読み物より実用ノウハウ。** note公式の分析では、売れている記事の平均価格は実用ノウハウ系1,842円、読み物系983円。だから連載は無料にして、有料は実用ノウハウに絞る
4. **伸びているジャンルは「AI活用」。** ただし汎用的なプロンプト集は飽和している。有料①は、AI本人の失敗ログという、ほかにない材料から作った

有料①と有料②の読者は、それぞれ「生成AIを仕事や副業で使っていて、答えの質に困っている人」と「noteで有料記事を売りたい人」。どちらも、自分のことをその言葉で呼ぶ人たちで、実在する。

## 3. スケジュール

**前提**：Xは依頼主のアカウントを使う（確認済み）。noteで有料記事を出せる状態かは未確認。
Xが使えなくなった場合は、下の表の「X投稿」を飛ばし、代わりに「3-2. Xを使わない場合」をやる。

公開日は、依頼主が投稿した日を「1日目」とする。

| 6日目 | X投稿⑥ | |
| 7日目 | **数字を記録**（下の記録表） | |

| 9〜13日目 | X投稿⑧〜⑫ | |

**有料②を21日目まで待つ理由**：有料②は「手順を書いたAIが、同じ手順を実行した結果」を載せるのが売り。数字がない状態で「売り方」を売ると、信頼されない。

### 3-2. Xを使わない場合

集客をnoteの中だけで行う。Xより人が集まるのは遅くなる前提で、判断の時期を30日目から45日目に延ばす。

- 無料記事を週2本に増やす。ネタは週報と、有料記事の見出し1つずつ（中身の一部を無料で書き、最後に有料記事へリンク）
- 記事のタイトルの前半に、noteで検索される言葉を入れる（「note 有料記事」「生成AI プロンプト」など）
- `hashtags.md` のタグを必ず付ける
- 同じテーマ（生成AI、note収益化）の他の人の記事を毎日数本読み、内容に触れたコメントを残す。スキだけで終わらせない

## 4. 投稿手順（毎回同じ）

1. noteで新規記事を作成し、記事ファイルの1行目（`# `のあと）をタイトルに、2行目以降を本文に貼り付ける
2. 「公開前の作業メモ」のブロックがあれば削除する
3. 有料記事は、「（▼ここに note の「有料エリア設定」ラインを入れる ▼）」の位置に有料ラインを設定し、その行と前後の `---` を削除する
4. 表やチェックボックス（`- [ ]`）が崩れたら、箇条書きに直す
5. `hashtags.md` から、その記事のタグを付ける
6. 見出し画像を付ける（noteの無料素材でよい）
7. プロフィールに次の一文を入れておく（1日目だけ）：
   「このアカウントの記事は、AI（Claude）が書いています。AIに『5万円で稼いで』と頼んだ挑戦の記録です。売上も失敗も全部公開します。」

## 6. 数字ごとの打ち手（変更は1回に1つだけ）

| 状況 | 原因の仮説 | 打ち手 |

## 7. 売上の見通し（保証ではない）

- 元手は0円。5万円は使わない。広告費は、無料で集客の型が見つかるまでは使わない（効果が測れないため）
- 受取額は、クレジットカード決済の場合、500円の記事が1件約427円、980円の記事が1件約838円（決済手数料5%と、その残りにかかる利用料10%を引いた額）。振込のたびに別途270円かかる
- 売上の目安は置かない。フォロワー0から始めて、1か月以上1件も売れない例も普通にある。30日目の数字で判断する

## 8. 依頼主が気をつけること

- 会社員の場合は、副業規程を確認する
- 第1話と有料①には、依頼主の発言がそのまま引用されている（名前は出していない）。気になる表現があれば変えてよい
- 記事中の数字は、検索結果の要約で確認したもの（この作業環境からは、noteや国税庁のページを直接開けなかった）。投稿前に、第2話の参照元を公式ページで一度確認する
- AIが書いた記事であることは、プロフィールと本文で明記している。この挑戦の価値の中心なので、隠さない
